# 第九轮迭代技术设计

## 一、 迭代背景与商业目标

本轮迭代聚焦于**“公众号贴图（微信版小绿书）流量红利与变现”**商业模式的系统化落地。

根据行业实操复盘，微信正在大力扶持“贴图”格式以抢夺碎片化阅读流量，该赛道具有“原创要求低、推荐算法形成信息茧房、变现路径清晰（流量主/私域/带货）”等显著特征。
为了承接这一巨大的流量红利，`next_content` 系统需要从“长图文深耕”模式，扩展出一条全新的**“极速贴图（短平快图文）生产线”**。

核心目标是实现：**搬运爆款 -> 智能洗稿提取短文案 -> 自动化前端排版生图 -> 一键发布** 的三分钟流水线。

---

## 二、 核心需求与场景拆解

### 2.1 商业痛点与 AI 解决方案对应

1. **封面与配图要求极高**（大字报、高饱和、直击痛点）：
   - *痛点*：纯靠大模型生图（Midjourney/DALL-E）无法精准控制中文字体和排版。
   - *方案*：引入前端 HTML/React 渲染到图片的方案（如 `satori` 或 `html-to-image`），AI 仅负责生成结构化文本（JSON），由前端模板负责视觉排版并导出连图。
2. **文案短平快且带钩子**（提供信息增量，留有评论钩子）：
   - *痛点*：现有的 Khazix 写作流太长、太深。
   - *方案*：新增针对性的“贴图短文案” Prompt，强制输出百字内、口语化、带互动的微型文案。
3. **素材极度依赖“低粉爆款”**：
   - *痛点*：需要更高效的爆款筛选。
   - *方案*：强化现有的采集与发现机制，为贴图专线提供源源不断的种子素材。

## 三、 系统架构与技术实现路径

### 3.1 贴图专线工作流 (Sticker Pipeline) 分叉

在现有的 8 环节 Pipeline 中，增加一个模式切换（`type`: `long-article` / `sticker`）。
当选择 `sticker`（贴图模式）时，工作流精简并重组为以下四个核心步骤：

1. **收集与种子提取 (Collect)**
   - 沿用小红书采集节点。
2. **微型文案洗稿 (Micro-Writing Agent)**
   - 替代原有的 Khazix 深度写作。
   - **输入**：采集到的爆款原文。
   - **输出 (JSON 结构)**：
     - `title`: 封面大标题（极具吸引力）。
     - `slides`: 包含 3-8 个子项的数组，每项包含 `heading` (副标题) 和 `content` (一句话核心观点)。
     - `caption`: 底部配套发布的短文案（含吐槽/钩子问题）。
3. **自动化排版生图引擎 (Visual Rendering)**
   - 替代原有的 AI 配图（Illustrate）。
   - 在 `src/lib/typeset` 或新组件中引入前端生图库（如 `html-to-image`）。
   - **实现机制**：系统读取步骤 2 的 JSON，将其注入到预设的 React 模板中（例如“高饱和度黄黑语录模板”），在不可见的 DOM 容器中渲染，随后自动批量截取为一组 JPG/PNG 轮播图。
4. **小绿书合规发布 (Publish)**
   - 组装生成的图片数组和底部短文案。
   - 调用微信公众号“图文素材”或“草稿”接口，注意默认开启“允许留言”选项。

### 3.2 新增与重构模块

1. **`src/lib/agents/sticker-writer.ts`**
   - 新增专用于小绿书贴图的写作 Agent。
   - 负责生成严格格式化的 JSON 供前端渲染。
2. **`src/components/StickerGenerator/`**
   - 新增专门的贴图可视化生成组件。
   - 包含多个预设样式（Themes），如职场金句风、养生大字报风、怀旧岁月风等。
3. **`src/components/ImageTab.tsx` 扩展**
   - 在图像面板中增加“文字排版生图（Text-to-Image-Template）”功能区，支持手动调试 JSON 和预览 9宫格 图片。

## 四、 阶段验收标准 (Definition of Done)

1. **短文案 Agent 落地**：能够稳定将一篇长笔记提炼为 1 个大标题 + 5 个以内核心分 P + 1 段带钩子的底部描述，并以 JSON 输出。
2. **前端排版生图引擎跑通**：基于 JSON 数据，前端能够通过模板（至少 2 套）成功渲染并一键下载完整的 1:1 或 3:4 比例的连图组合。
3. **Pipeline 兼容**：主 Pipeline 能够识别 `sticker` 模式，跳过长文打分/审核，顺利完成“采集 -> 提取 JSON -> 渲染出图 -> 组装”的全链路。
4. **微信接口适配**：能够将生成的图片组和描述成功推送到微信后台，形成规范的“贴图”草稿。
